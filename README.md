# 233 固件介绍页

这是介绍 Snapmaker U1 社区固件的静态网页。GitHub Pages 从 `main` 根目录部署。可在本地运行 `python3 -m http.server 8000` 预览。

页面使用 233 Screen 的暖色主题。触屏和耗材管理图片来自实机，封面是概念图。可交互的槽位示例用于解释料路。
